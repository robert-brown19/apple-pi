The key tools in the security analysis of most military and government assets are Tenable NESSUS Vulnerability Scans and Secure Configuration measured against official checklists.  In the DOW they are called Secure Tecnical Implementation Guides (STIG) and they are provided at https://www.cyber.mil .
I will be using the [Security Content Automation Protocol (SCAP) Compliance Checker](https://www.niwcatlantic.navy.mil/Technology/SCAP/)
